Einmalig mit GitHub verbinden

Damit die Seite sich selbst speichern kann, braucht sie einen Zugangsschlüssel (Token) nur für dieses Repository. Er bleibt in diesem Browser und wird sonst nirgends gespeichert.

1. GitHub öffnen: Profilbild, Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token.
2. Repository access: Only select repositories, dein Playbook-Repo wählen.
3. Permissions, Repository permissions, Contents: Read and write.
4. Token erzeugen, kopieren und hier einfügen.
